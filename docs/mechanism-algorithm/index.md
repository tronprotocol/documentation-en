# Understand the TRON protocol

Documentation about TRON consensus, Super Representatives, accounts and signatures, network resources, system contracts, and account permissions.

## Recommended reading order

1. [DPoS consensus](dpos.md) — Consensus concepts, block production and solidification, Super Representative elections, incentives, and proposal-based parameter changes.
2. [Super Representatives](sr.md) — Super Representative candidacy and elections, block and voting rewards, and committee proposal operations.
3. [Account model](account.md) — Account creation and activation, key-pair and address generation, and signature creation and verification.
4. [Resource model](resource.md) — TRON Power, Bandwidth, Energy and fee limits, dynamic Energy, staking, delegation, unstaking, and resource APIs.
5. [System contracts](system-contracts.md) — `ContractType` overview and protobuf fields for java-tron system contracts.
6. [Account permission management](multi-signatures.md) — Permission levels and structures, fees and constraints, update and signing workflows, auxiliary interfaces, and examples.
